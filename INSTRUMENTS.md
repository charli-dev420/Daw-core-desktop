DAWWW-CORE currently ships **50 dedicated synthesis engines plus one sampler**. The table below is a practical production reference: **role**, **character**, **what to listen to first**, and **processing that commonly fits the source**.

> **“Adjust first” is a listening priority, not a promise that every editor uses identical control names.** Each dedicated instrument can expose controls suited to its sound engine.

## A practical way to choose

1. **Choose the musical role first** — bass, chord bed, lead, texture, transition, percussion.
2. Pick the engine whose **raw character is already close** to that role.
3. Adjust the source before inserting processors.
4. Use the [16-effect catalog](EFFECTS.md) only for a problem or color you can describe.
5. Check the result in the mixer, not only in solo.

This is also the recommended learning path on the site:

**Instrument → source shaping → effects → mixer → export**

## Project and cross-device behavior

Instrument state belongs to the DAWWW-CORE project model rather than a Desktop-only preset layer. The `.dw` contract is designed to move the project between Desktop and Android without creating a reduced mobile project format.
